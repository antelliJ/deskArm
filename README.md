A 3d printable desk mount that clamps onto the desk

Using various pivot points, the arm is able to move along the major axis

The ends are intended to be swappable for different bits, for a mic and potentially for a standardized tripod mount and/or a phone mount

## File organization
`Exports/Editable Cad files` 
Has some `.step` files, but the original Free Cad file is at the root directory

`Exports/Print Ready Files/` Houses the 3mf files,
`Exports/Print Ready Files/joint 4mm/` is where the joints are that are double checked to be consistent

`Exports/Render Stl/` stores the stl files used for the render

A lot of variation can be made from making your own pieces that use the standard connectors, so the things you choose to and not to print can drastically change what you need, in filament and thte amount of connectors you use. For instance, I already have some clamps I intend to use on my desk that I expect to be stronger than a 3d printed version, so for me I wouldn't print that. I also don't need that much extra length from many connectors.

M3.5 - M4 are just the smallest ones I had on hand, but it should be easy enough to drill / hand-thread bigger bolts in
