A 3d printable desk mount that clamps onto the desk



Using various pivot points, the arm is able to move along the major axis

The ends are intended to be swappable for different bits, for a mic and potentially for a standardized tripod mount and/or a phone mount

## File organization
`Exports/Editable Cad files` 
Has some `.step` files, but the original Free Cad file is at the root directory

`Exports/Print Ready Files/` Houses the 3mf files,
`Exports/Print Ready Files/joint 4mm/` is where the joints are that are double checked to be consistent


Built using FreeCAD

Inspiration taken from [Makerworld](https://makerworld.com/en/models/2719135-parametric-universal-boom-arm)
